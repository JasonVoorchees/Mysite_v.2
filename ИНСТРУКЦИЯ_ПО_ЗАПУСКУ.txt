ИНСТРУКЦИЯ ПО НАСТРОЙКЕ И ЗАПУСКУ TREZO (Django)
===============================================

Документ описывает локальный запуск сайта Trezo. Фронтенд (HTML/CSS/JS)
перенесён без изменений, поэтому все стили и функции должны работать так же,
как в исходной версии.

1. Предварительные требования
-----------------------------
* Git.
* Python 3.11+.
* PostgreSQL 15 (или совместимая версия).
* Библиотеки для Pillow (libjpeg, zlib) при установке зависимостей.

2. Получение исходников
-----------------------
```bash
git clone <адрес-репозитория>
cd Mysite_v.2
```

3. Переменные окружения
-----------------------
Приложение читает параметры из переменных окружения. Для локального запуска
удобно создать файл `.env` со значениями по умолчанию:
```env
DJANGO_SECRET_KEY=замените-на-случайное-значение
DJANGO_DEBUG=1
DJANGO_ALLOWED_HOSTS=localhost 127.0.0.1 [::1]
POSTGRES_DB=trezo
POSTGRES_USER=trezo
POSTGRES_PASSWORD=trezo
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
```
Файл можно загрузить командой `export $(cat .env | xargs)` в macOS/Linux или
с помощью `set` в PowerShell. На Windows обязательно укажите `POSTGRES_HOST=localhost`.

4. Локальный запуск
-------------------
1. Создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate          # Windows: .venv\Scripts\activate
   ```
2. Установите зависимости:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
3. Выполните миграции и при необходимости создайте администратора:
   ```bash
   python manage.py migrate
   python manage.py createsuperuser    # по желанию
   ```
4. Соберите статические файлы для продакшн-режима (не обязательно для runserver):
   ```bash
   python manage.py collectstatic
   ```
5. Запустите сервер разработчика:
   ```bash
   python manage.py runserver
   ```
6. Откройте http://127.0.0.1:8000/ и проверьте, что фронтенд отображается корректно.

5. Работа с медиа-файлами
-------------------------
* Пользовательские изображения сохраняются в каталоге `media/`.
* В продакшн-среде рекомендуется настроить отдачу медиа через Nginx или CDN.

6. Диагностика типовых проблем
------------------------------
* **Django жалуется на ALLOWED_HOSTS.** Добавьте нужные адреса в переменную окружения
  `DJANGO_ALLOWED_HOSTS` (через пробел). По умолчанию разрешены `localhost`, `127.0.0.1` и `[::1]`.
* **Ошибки Pillow.** На локальной машине установите системные библиотеки libjpeg и zlib,
  затем повторите установку зависимостей.

Следуя указанным шагам, вы получите полностью работающее Django-приложение Trezo с
оригинальными стилями и JavaScript-функциональностью при локальном запуске.
